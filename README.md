# ICM Preflop Lab

토너먼트(MTT) 프리플랍 GTO 솔버 웹앱. 2~8인 테이블에서 좌석별 스택, BB 앤티, 상금 구조(ICM)를 반영해
핸드별 액션 빈도와 EV(ICM · Chip)를 13×13 차트로 보여준다.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 엔진 테스트 (ICM, 평가기, 트리, 솔버 검증, 병렬 동등성)
npm run build
npm run gen:equity -- 100000   # 169×169 에퀴티 테이블 재생성 (선택)
```

## 게임 모델

**액션 트리**
- 오픈(사이즈 설정), SB 림프, 3벳(IP/OOP 배수 + 스퀴즈 콜러당 추가), 4벳, 올인
- 사이즈가 스택의 `올인 전환 비율` 이상이면 해당 사이즈를 빼고 올인만 남긴다
- 콜로 팟 인원이 4명 이상이 되는 라인은 제외. 단, 액션을 닫는 마지막 콜(올인 아님)은 4인까지 허용
- 3벳 이후 콜드콜 불가 (올인에 대한 콜은 가능), 콜드 4벳은 올인만

**종료 노드 가치**
| 종료 유형 | 계산 방식 | 정확도 |
|---|---|---|
| 모두 폴드 | 칩 이동 → ICM | 정확 |
| 2인 올인 | 169×169 에퀴티 × ICM, 카드 제거 반영 | 정확 (클래스 단위) |
| 3인 올인 | 1:1 에퀴티의 독립 가정으로 순위 확률 근사, 사이드팟 반영 | 근사 |
| 플랍 진행 (2~4인) | 에퀴티 × EQR(포지션·SPR·핸드 플레이어빌리티) → 승자 추첨, 패자는 `팟 성장`만큼 추가 손실 | 휴리스틱 |

ICM EV 단위는 핸드 시작 시점 대비 상금 풀 지분 변화(%p), Chip EV는 칩 변화(bb)다.
블라인드와 앤티 투입분이 포함되므로 BB의 폴드 EV는 `-(1 + 앤티)`bb다.

**솔버**
- 169 클래스 벡터 DCFR (α=1.5, β=0, γ=2), 동시 갱신
- 카드 제거는 히어로와 각 상대 사이에만 반영 (상대끼리의 블로커는 무시)
- 착취 가능도 = 플레이어별 베스트 리스폰스 이득의 평균. ICM은 제로섬이 아니라서 수렴 보장은 없고 수치로 확인한다

## 검증

- 헤즈업 10bb Chip EV 푸시/폴드: SB 푸시 58.2%, BB 콜 37.3% (알려진 내시 결과 약 58% / 37%)
- 3인 버블 ICM: BTN 올인에 대한 BB 콜 범위가 Chip EV 11.4% → ICM 2.1%로 좁아짐
- 병렬 솔브 결과가 단일 스레드와 부동소수점 오차 내에서 일치

## 한계와 다음 단계

- 포스트플랍은 EQR 휴리스틱. 헤즈업/3-way 포스트플랍 솔브로 EQR을 보정하는 것이 2단계
- 3인 올인은 독립 가정 근사. 3인 에퀴티 테이블을 미리 계산해 정확도를 올릴 수 있음
- ICM은 테이블 인원만 계산 (다른 테이블 스택, FGS 미지원)
- 핸드 클래스 단위(169)라 같은 클래스 안 수트별 블로커 차이는 반영하지 않음
